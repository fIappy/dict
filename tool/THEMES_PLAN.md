# 主题词汇：全覆盖分类的作业说明

本文件是「把 COCA 前 20,000 全部归入主题场景」这件事的**操作手册**。
按它分段做，每次做完一批重新跑一次生成器，覆盖率自己会往上走。

## 1. 文件与角色

| 路径 | 作用 | 谁改 |
|---|---|---|
| `tool/themes_lexicon.json` | **分类法**（场景 id / 名称 / 说明 / 子类）+ 初始策展词 | 只在要增删场景时改 |
| `tool/themes_batches/NNN.txt` | **分批归类结果**（新增的都是这个） | 每批新建一个 |
| `tool/themes_pending.txt` | 待办队列（生成器产出，勿手改） | 自动 |
| `tool/build_themes.dart` | 合并 + 校验 + 生成 | 一般不动 |
| `assets/data/themes.json` | App 读取的资产（生成物，勿手改） | 自动 |

批次优先级高于策展词表，所以后写的批次可以**纠正**先前的判定。

## 2. 分类法（id 必须原样使用）

## 3. 批文件格式

`tool/themes_batches/001.txt`：

```
# 001 — COCA ranks 1-400
# 一行一个词：词<TAB>场景:子类[,场景:子类]...
the	general:function
be	general:function
abandon	work:action,emotion:state
hospital	medical:thing
```

规则：

- `#` 开头是注释，空行忽略；
- 词与归属之间用 **Tab 或空格** 分隔；
- 归属写成 `场景id:子类id`，多个用逗号连接；
- 一个词**最多 3 个场景**（超过会被生成器报错）；
- 同一个词可以在不同批次里再次出现，后出现的覆盖先前的同一场景判定；
- 词必须存在于 `coca-20000.txt`，否则报错。

## 4. 每批怎么做

```bash
# 1. 看队首 400 个待办词
sed -n '5,404p' tool/themes_pending.txt

# 2. 写成 tool/themes_batches/001.txt（下一个批次号往下顺延）

# 3. 合并 + 校验 + 刷新队列
dart run tool/build_themes.dart --pending
```

生成器会打印：场景数、归属数、覆盖率、剩余待办；**有任何错误会以非零退出码结束**
并逐条列出（不在 COCA、场景 id 写错、子类 id 写错、同一场景重复、超过 3 个场景）。

最后跑一次全量验证：

```bash
flutter test && flutter analyze
```

`test/themes_test.dart` 会检查：资产可解析、场景计数与子类一致、**每个词都在 COCA
且严格按词频排序**、子类内无重复。

## 5. 判定规则（保证跨批次一致）

1. **先判断有没有具体场景**：没有任何场景能自然容纳 → `general`。
2. **虚词一律 `general:function`**：冠词、介词、连词、代词、助动词、be/have/do 的
   助动用法。`be` 的实义（存在）也归 function，避免把最高频词塞进具体场景。
3. **多场景只在真的都成立时给**：`train` 在城市出行 / 旅行住宿 / 校园学习都成立；
   `bank` 在金融（机构）与自然（河岸）成立。宁少勿滥，上限 3。
4. **子类按"这个词在这个场景里扮演什么"判定**，不是按词性一刀切：
   - `clean` 在 home 是 `action`；`clean` 在 environment 是 `state`（干净的）；
   - `work` 在 work 场景既是 `action`（工作）也是 `thing`（工作/作品）—— 取更能代表
     该场景的那一个，同一 (场景,词) 只能有一个子类。
5. **抽象高频词**（idea、system、process、value…）优先看能否落到 tech/work/science；
   落不进去就 `general:state`。
6. **专有名词**（人名地名机构名）不进场景，除非是通用化的（`paris` 不进 travel）。
7. **一词多义**按高频义项判定；次要义项只有在场景差异明显时才加第二个场景（如 bank）。

## 7. 注意事项

- **不要改场景/子类的 id**：App 与资产都按 id 索引，改 id 等于让历史批次全部失效。
- **不要手改 `assets/data/themes.json`**：它是生成物，下次 `dart run` 会覆盖。
- 新增场景时才动 `themes_lexicon.json`，并在本文件第 2 节同步补一行说明。
- 批文件按文件名排序合并，所以编号要用三位零填充（`001.txt`、`002.txt`…）。
